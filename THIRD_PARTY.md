# Third-party notes

This project uses **TikTokLive 7.0.1** by Isaac Kogan.

- Project: https://github.com/isaackogan/TikTokLive
- TikTokLive is an unofficial reverse-engineered client for TikTok LIVE.
- The upstream project describes itself as not production-ready and recommends a managed WebSocket API for production workloads.
- The upstream package is distributed under a modified AGPL-3.0 license. Review its LICENSE before redistributing or commercializing software that incorporates it.

This project does not claim to prevent TikTok restrictions. Diagnostic events are used for observability and conservative pausing of automation.
