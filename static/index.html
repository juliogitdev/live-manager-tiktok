Integração Roblox

O script deve ficar em ServerScriptService. Nunca exponha a API key em LocalScript.

O bridge usa long polling, registra a sessão automaticamente e se recupera de restart do Render.

POST /api/bridge/register
GET /api/bridge/<session>/poll?after=<cursor>&wait=8

Ao iniciar o Roblox, o cursor começa no evento mais recente para evitar repetir presentes antigos.
